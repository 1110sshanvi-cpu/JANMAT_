JANMAT v0.2 — FROM VOICE TO LAW
================================

WHAT THIS IS
A browser-based educational prototype for a school exhibition on "Inside the Indian Parliament".
It contains a mock public concern, fictional Bill, amendment choices, Treasury Bench and Opposition
arguments, a visitor's role, a classroom vote illustration, a short knowledge quiz and a process explainer.

HOW TO RUN ON WINDOWS
1. Extract the downloaded JANMAT_v0_2.zip file.
2. Open the extracted folder and then open "janmat-v0.2".
3. Double-click index.html. It should open in your web browser.
4. To put it on your desktop: right-click index.html > Show more options (if shown) >
   Send to > Desktop (create shortcut).

No Python, account, installer or internet connection is required for the app's core features.
The optional font may load from the internet; if not, system fonts are used.

IMPORTANT CIVICS NOTE
JANMAT is a simplified classroom simulation, not an official reproduction of parliamentary procedure.
The scenario is fictional. The vote tally is illustrative, not actual parliamentary data. An ordinary
Bill generally needs passage by both Houses and Presidential assent, but special procedures apply to
some types of Bills. Please verify factual statements with your teacher / official civics materials.

JANMAT v0.3 — ADVANCED VERSION
-----------------------------
This version keeps the original v0.2 mock Parliament simulation and adds an Explore Parliament learning hub with three topics:
1. What is Parliament? (Lok Sabha, Rajya Sabha, key functions)
2. People of Parliament (selected former parliamentary figures)
3. Parliamentary Sessions (Budget, Monsoon and Winter)

HOW TO OPEN
1. Extract the ZIP file first.
2. Open the folder JANMAT_v0.3/janmat-v0.3.
3. Double-click index.html.
4. Use the “Explore Parliament” button on the home screen to open the learning hub.

No installation, server, account, or internet connection is required for the core app. Internet is needed only if you choose to open the official-source links.

IMPORTANT
- The mock Bill, role-play, and vote tally are educational simulations, not actual parliamentary proceedings.
- Session months are typical periods, not guaranteed dates. Verify facts against official sources before presenting.
- The people list is a short selection, not a complete list.
